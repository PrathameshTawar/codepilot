Engine Architecture

Built with defense-in-depth safety.

📂

Traversal-Safe Repository Reader

Scans the codebase with strict boundary bounds, ignoring binary and lock files, extracting full AST context without memory bloat.

🛡️

Atomic AST Patch Engine

Pre-validates Python syntax trees prior to writing to disk. If an invalid token is detected, an instantaneous atomic rollback occurs in <12ms.

🧪

Process-Isolated Sandbox

Executes pytest in segregated worker subshells with hard 15s timeout protection, preventing fork bombs and runaway background processes.
